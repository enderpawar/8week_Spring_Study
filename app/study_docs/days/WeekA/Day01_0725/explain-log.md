# Day01 (7/25, Week A D1) 예측→실행→차이설명

형식: 개념 | 예측 | 실제 결과 | 차이 설명(왜 이렇게 동작하나)

| 개념 | 예측 | 실제 결과 | 차이 설명 |
|---|---|---|---|
| `/hello` GET 호출 | 200일 것 같다(막연히) | 200 OK | 예외 없이 정상 반환 = Spring이 자동으로 200 부여 |
| `/nope`(미등록 경로) 호출 | 404일 것 | 404 Not Found | 매핑된 핸들러 없음 → Spring이 자동 반환. 400/404는 "명시적 신호"가 있어야 나온다는 걸 확인 |
| `/health` (`HttpStatus.OK` 명시) | 여전히 200일 것 | 200 OK | 기본값과 명시값이 같아서 겉보기엔 차이 없지만, 코드상 "의도적으로 선택한 상태코드"로 바뀜 |
| `/bye` (`HttpStatus.CREATED`, 최초엔 `201` 정수) | 201 Created | 컴파일 에러 4개(미완성 구문·import 누락·세미콜론 누락·메서드명 중복) 먼저 발생, 수정 후 201 | 컴파일러는 애노테이션이 아니라 메서드 이름+파라미터만 보고 중복을 판단한다는 걸 실제 에러로 체감 |
