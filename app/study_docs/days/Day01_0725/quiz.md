# Day01 (7/25, Week A D1) 문제집 — 요청→응답 왕복

형식: 문제 → <details> 정답/해설 (접힘)

## Q1. `hello()` 메서드에 상태코드를 명시하지 않았는데 왜 200이 나왔을까?

<details>
<summary>정답/해설</summary>

HTTP 상태코드 5계열: 1xx(정보) / 2xx(성공) / 3xx(리다이렉션) / 4xx(클라이언트 오류) / 5xx(서버 오류).
200은 2xx 대표, 네트워크 시간에 배운 400/404는 4xx 계열.

핵심: **컨트롤러 메서드가 예외 없이 정상 반환하면 "이상 신호 없음 = 성공"으로 간주해 기본값 200을 붙인다.** 400/404가 나오려면 명시적으로 신호가 필요 (404=매핑된 핸들러 없음/자동, 400=검증 실패/D3에서 다룸).

**1차 시도 오답** — "DTO로 미리 저장돼서"라고 답함. DTO(응답 데이터 형태)와 상태코드(응답 메타데이터)는 무관한 별개 개념 → **+1일 오답 재시험 대상** (복습큐 등록).
</details>
