# Day07 (2026-08-02 완료, Week A D7) — 버퍼 / 기술부채 상환

## 완료 범위

- Day03·04에서 Week A D7에 배정한 즉시 수정 부채를 처리했다.
- 저장 계약을 “ID 없음은 추가, 기존 ID는 같은 위치 교체”로 확정했다.
- 조회 실패를 `Optional`로 표현하고 Service가 `ReservationNotFoundException`으로 변환했다.
- 없는 예약은 404, 경로 ID가 0 이하면 400으로 응답하도록 웹 경계를 구성했다.
- 예상하지 못한 예외의 상세 정보는 서버 로그에 남기고 500 본문에는 일반 메시지만 반환한다.
- Spring MVC 내장 메서드 검증을 사용해 `@Positive` 경로 제약을 처리했다.
